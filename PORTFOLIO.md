# Website project summary

`portfolio-summary.json` is the public summary for the featured project on
https://cakirtufan.github.io/. The website card reads it from this repository's
`main` branch when a visitor opens the page. Update this file alongside the
README when a milestone is ready to share, then commit and push it.

The website displays the title, status, summary, finding, completed work,
next step, technologies, and update date. Keep the text short and suitable
for portfolio visitors. This is a curated summary, not an automatic rewrite
of the README or an automatic interpretation of experiment results.

No scheduled workflow or cross-repository secret is needed. GitHub caching
can delay the appearance of an update. If JavaScript is disabled or the
request fails, visitors see the description embedded in the website page.

Initial installation requires publishing the prepared `_pages/about.md`
change in the website repository. Subsequent summary updates only require
a push to this repository.
